# 小财通（XiaoLiCaiTong）

> **市面上的理财 App 都靠你多交易赚钱；小财通不靠你交易，它只想让你看清楚。**

你可能也有过这种感觉：

- 基金买在支付宝、天天基金、银行，东一只西一只，**从没在一个地方看清自己到底有多少钱、赚了还是亏了**；
- 一打开 App，满屏热门推荐、涨跌推送、“老师带单”，**真正和你有关的消息，被淹没在噪音里**；
- 看到财报、公告、政策，全是术语，**看不懂，也不知道跟自己的基金有没有关系**；
- 想设个提醒，却得自己天天盯着，关键变化还总漏掉；
- 更别扭的是——**这些平台本质是卖基金的，它们的立场，未必站在你这边。**

小财通就是为这件事做的：一个**本地运行、没有账号、不连交易**的私人基金助手，把判断权交还给你。

### 它替你做四件事

|   | 你不用再…… | 小财通帮你…… |
|---|---|---|
| **筛** | 每天刷上百条消息 | 只留和你持仓真正有关的那几条，宁少勿滥 |
| **拆** | 对着术语和公告发懵 | 用大白话讲清发生了什么、为什么和你有关、该继续观察什么 |
| **盯** | 自己天天盯盘、怕漏 | 设好条件它替你盯着，没事不打扰，到点才提醒 |
| **记** | 每次重新开始、没法复盘 | 记下你买过什么、为什么买、结果如何，帮你复盘自己的判断 |

### 为什么可以放心把它放在身边

- **立场中立**：不卖基金、不抽佣金、不带货，没有任何动机劝你买卖；
- **隐私在自己手里**：本地运行，无账号、不注册，持仓数据只存在你自己的设备上；
- **只摆事实，不替你下结论**：不荐基、不预测涨跌、不承诺收益，只整理客观数据和公开信息，决定始终由你自己做；
- **双端可用**：Windows 桌面 + Android 手机，安静、免费。

> 它不是缩小版的支付宝，也不是又一个喊单群，而是一个**安静、懂你持仓、会帮你把事情讲清楚的助手**。

> **这是 Preview 预览版，不是正式版。** 两端能力不同，下面逐项写清楚；未实现或有限制的功能会明确标出，不用示例数据冒充真实数据。
>
> - **Windows**：Python + pywebview + SQLite 桌面版（便携 ZIP，不需要另装 Python）
> - **Android**：Capacitor + 原生 SQLite 的手机 App
> - **本地优先**：没有账号系统，不上传持仓；不连接支付宝/天天基金，不替你买卖基金

## 一、Windows 版（便携 ZIP）

### 已接通

- **首页五区块**：资产总览、市场速览、今日提醒、市场事件、值得关注；真实数据，空数据展示真实空态
- **我的基金**：搜索、添加（持有/仅关注）、成本价 + 份额、真实净值、市值、累计收益、今日盈亏、持仓记录、清仓/历史持仓、删除
- **市场事件**：SEC EDGAR + 美联储 + 美国劳工统计局（BLS）官方源，实时 7 天 / 财报 14 天保留；收藏 / 忽略 / 已读状态写入本机 SQLite；「市场发现」展示官方源中没有匹配到持仓的真实事件，不再是占位页
- **盯盘提醒**：规则真实保存（添加/编辑/暂停/删除/重启保留）；检查引擎与触发历史已接通；Windows 通知同时走系统 Toast 和应用自绘 TopMost 横幅，手动免打扰时横幅仍可显示；市场对象 14 个（9 个指数 + 4 个赛道 ETF + 1 个黄金 ETF）
- **研究工具**：发现 / 赛道·黄金 / 基金经理 / 全球市场四个 tab；行情、官方新闻、基金经理均来自真实公开源与本机 SQLite；基金经理显示源站“现任经理”，不伪造历史业绩
- **组合体检**：真实读取本地持仓，展示总市值、总成本、浮动盈亏、集中度与数据截止提示，不评级、不荐基
- **设置**：浅色/深色与主题色；通知总开关；后台运行、关闭到托盘、Windows 登录自启的真实开关；品牌预览
- **「更多」菜单**：研究工具与设置；原 `coming-soon.html` 直接跳转研究工具，不再摆占位页
- **品牌**：桌面窗口、任务栏、EXE、安装包、手机端与启动图统一使用用户指定的 Python 文件图标（纸页 + Python 双蛇），页头同时显示「小财通」文字
- **r4.3 体验修正**：美联储/BLS 等英文市场事件自动翻译成中文，事件卡优先中文标题并标「自动翻译」+英文原文；首页、基金页、市场事件统一显示同一个刷新周期（净值与事件同一次抓取）；每次启动刷新一次，手动「刷新数据」走同一刷新链路

### 安装

1. 把 `XiaoLiCaiTong-Windows-v0.1.0-preview-r4.3-portable.zip` 解压到**可写且路径较短**的文件夹（例如 `D:\XiaoLiCaiTong`，不要放在 `Program Files`）。
2. 双击 `XiaoLiCaiTong.exe`；启动默认进入首页。
3. 首次启动会在 exe 同目录创建 `data/xltc.db`（空库），不会带入任何人的真实持仓。
4. Windows 10/11 需要 WebView2 Runtime；Windows 11 通常自带，Windows 10 如提示缺失请安装 Microsoft WebView2 Runtime。

> **路径要求**：解压后的完整路径（从盘符到 `XiaoLiCaiTong.exe`）请保持在 180 字符以内。本版在启动前会检查路径长度，过长时会弹出中文提示并安全退出（不会创建数据库，也不会启动后台线程）。若看到该提示，请把**整个文件夹**（连同 `data/`）移动到更短的路径后重新打开。

### 数据位置

- Windows 用户数据在解压目录的 `data/` 下；移动软件时连同 `data/` 一起移动。
- `data/` 是个人隐私，不要上传或发给别人。

### 已知限制

- 未签名 Preview：Windows SmartScreen 可能提示“未知发布者”，需手动允许。
- 市场事件里的 SEC 源需要本机环境变量 `XLTC_SEC_CONTACT_EMAIL`（填入你自己的联系邮箱）；未配置时 SEC 源不可用，美联储源不受影响。
- Windows 系统通知总开关关闭时，系统 Toast 不会显示；应用自绘横幅是独立窗口，但仍受系统桌面/全屏应用影响，不等于系统级推送通道。
- 基金经理只显示源站现任经理，不提供历史业绩曲线；赛道/黄金使用对应 ETF 作为代理，不是指数或现货本身。
- 关闭到托盘与 Windows 登录自启可在设置中真实开关；自启写的是当前用户 HKCU Run，重启后的最终行为需在目标机验收。
- 数据源是免费公开接口，可能临时不可用；失败时保留上次真实数据，不会覆盖成假数据。

## 二、Android 版（debug APK）

### 已接通

- **底部 5 Tab**：首页 / 基金 / 事件（市场事件与市场机遇） / 记账 / 我的；盯盘提醒为基金页子页，不占底部 Tab
- **首页**：真实总资产、累计收益、今日盈亏、持有数、最近刷新；真实指数行情；值得关注列表
- **我的基金**：真实搜索、添加、净值、成本、市值、盈亏、清仓、删除、刷新、已清仓
- **市场事件**：通过 CapacitorHttp 抓取美联储与 BLS 官方 RSS，写入本机缓存；支持收藏 / 已读；网络失败时展示缓存或明确提示，不编造新闻
- **盯盘提醒**：指数与基金规则可添加、编辑、暂停/启用、删除、持久化；用真实行情/最新净值判断；触发历史写入本机 SQLite；Android 本地通知已接入
- **r5.2 修正**：盯盘提醒规则支持编辑（提醒对象、条件类型、方向、触发值、触发后行为、备注均可改），保存后按新条件重新评估，不再需要删掉重建；与 Windows 端编辑能力对齐
- **我的**：版本、数据来源、本地隐私说明、通知权限、主题切换
- **本地 SQLite 持久化（DB v4）**、断网保留上次真实净值、前台手动/自动刷新
- **r4.3 体验修正**：弃用暖金色，统一蓝色体系；首页只做今日快照与事件摘要，基金页独立展示「资产总览 · 完整组合」；市场事件英文标题/摘要自动翻译；首页、基金页、事件页共享同一刷新时间，每次启动刷新一次
- **品牌**：各密度启动图标、圆形图标、自适应图标前景与启动图统一为用户指定的 Python 文件图标

### 安装

- 安装 `XiaoLiCaiTong-Android-v0.1.0-preview-r5.2-development-debug.apk`（见 Releases 附件）；Android 会提示“允许安装未知来源应用”，这是侧载 Preview 的正常提示。
- 包名：`com.keepjtl.xiaolicaitong`；最低 Android 7.0（API 24）。
- **签名说明**：本轮用于检查的 APK 是本机 debug 签名（v2 签名验证通过），不是正式商店包；原 release 签名材料已不在本机，且不会随仓库分发。正式 release 包需要补回原签名材料，或明确确认使用新的签名身份。
- 首次使用盯盘提醒时，系统会请求通知权限；请允许，否则只能看到应用内触发记录，收不到系统通知。

### 已知限制（Android 与 Windows 的差异）

- **盯盘检查只在应用前台运行**：打开应用时按 60 秒检查一次，切回前台时补检；应用被系统杀死或长期后台时，不保证继续盯盘，也不保证按时弹通知。
- 市场事件只使用美联储与 BLS 官方 RSS，不是全市场新闻聚合；没有公司级新闻匹配。
- 手机本地 SQLite 保存在应用沙箱；卸载应用会删除本地数据。
- 数据来源：天天基金公开接口（净值）、公开指数行情源、美联储/BLS 官方 RSS；不是基金公司官方 App，净值可能有延迟。

- Windows：SQLite 在解压目录 `data/xltc.db`；Android：SQLite 在应用沙箱。
- 仓库与安装包**不包含**真实持仓数据库、备份、邮箱、API Key、SSH 私钥或签名密钥。

## 四、从源码运行/构建

### Windows（开发）

```bat
python -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe -m app.main
```

便携版构建：

```powershell
.venv\Scripts\python.exe -m pip install pyinstaller==6.22.3
powershell -ExecutionPolicy Bypass -File packaging/windows/build.ps1
```

### Android

> 手机端（Capacitor 工程）目前单独维护，尚未随本仓库发布；下面命令供持有该工程目录时使用。可直接安装包见 Releases 附件。

需要 Node.js ≥22、Android Studio/SDK 36、Build Tools 36、JDK 21（Gradle 8.14 不支持 JDK 25）。

```bash
npm install
npm run build
npx cap sync android
cd android
gradlew.bat assembleRelease
```

Release APK 的 keystore 必须放在仓库外，通过 `keystore.properties`/环境变量注入；**不要提交签名密钥**。
