# 小财通（XiaoLiCaiTong）

一个**只在你自己电脑上运行**的个人基金管理小工具：把"我买了哪些基金、现在值多少钱、赚了还是亏了"集中管起来。

- **技术栈**：Python + pywebview（把网页界面装进桌面窗口）+ SQLite（本地数据库）
- **本地优先、单用户**：数据全部存在本机 `data/xltc.db`，没有账号系统，不上传云端
- **不做的事**：不荐股、不预测涨跌、不承诺收益；不做交易（不连接支付宝/天天基金，不会替你买卖基金）

> 项目目前处于 **MVP 开发阶段**，不是完成品。

## 四、安装（换电脑 / 重装时才需要）

当前 `.venv` 已经装好依赖，**正常运行不需要重新安装**。需要重建环境时，在项目根目录执行：

```bat
:: 1) 创建虚拟环境（本项目的 .venv 就是这样建的，记录在 .venv\pyvenv.cfg）
python -m venv .venv

:: 2) 安装依赖
.venv\Scripts\python.exe -m pip install -r requirements.txt
```

> 注：本项目当初安装时遇到清华镜像缺少部分包，改用官方源（PyPI）才装成功。如果重装时报"找不到包"，加上 `-i https://pypi.org/simple` 再试。

## 五、启动

**Windows（当前实际使用的方式）**

- 双击项目根目录的 **`启动小财通.bat`** —— 这就是正式入口
- 或者手动执行（必须在项目根目录，必须用 `-m` 写法）：

```bat
cd /d D:\Projects\XiaoLiCaiTong
.venv\Scripts\python.exe -m app.main
```

启动后：初始化数据库 → 启动本机网页服务（仅本机可访问）→ 弹出桌面窗口，默认打开「我的基金」页。

> ⚠️ 启动后**不要关闭那个黑色命令行窗口**，关掉它软件就退出了。

**macOS**：无法确认 —— 项目里没有 Mac 启动脚本，也从未在 Mac 上验证过。

## 六、项目目录说明

| `CLAUDE.md` | 项目规则与需求记录 |

## 七、本地数据说明

- **数据库位置**：`data/xltc.db`（首次启动自动创建）
- **备份目录**：`data/backup/`
- **不进 Git**：`.gitignore` 已忽略 `*.db` 和整个 `data/backup/`；`data/` 下**没有任何文件**被提交到仓库
- **没有密钥**：本项目用的都是免费公开数据源（akshare、腾讯行情、新浪行情），**不需要任何 API Key**
- **隐私提醒**：数据库里是你的真实持仓记录，属于个人隐私，**不要手动上传或发给别人**
