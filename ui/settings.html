设置
外观、通知、后台运行与登录自启动均已接通；所有开关写入本机，不伪装可用。
外观
外观模式切换后立即生效，并记住在本机。
主题颜色只用于按钮、导航、链接和重点元素；红涨绿跌不受影响。
品牌图标桌面窗口、任务栏、安装包、手机端与启动图使用同一套“Python 文件图标 + Python 双蛇”品牌。

通知
通知总开关（市场事件 + 盯盘提醒）关闭后只影响是否弹出系统通知，不影响规则检查。
测试通知发送一条真实 Windows 通知，确认能否收到。
系统通知设置收不到时，检查 Windows 通知总开关或勿扰模式。
关闭后，盯盘规则仍会继续检查，触发记录仍保存，但不弹 Windows 通知；如需停止监控，到「盯盘提醒」暂停规则。手机版已接 Android 本地通知，但只在应用前台时按 60 秒检查，离开应用不保证持续盯盘。
数据与隐私
数据来源天天基金公开净值接口；行情来自公开行情源。
数据保存持仓、设置只保存在本机 SQLite；没有账号系统，不上传云端。
提醒与通知盯盘提醒由后台引擎每 60 秒检查，触发后自动推送；免打扰下用桌面横幅。
